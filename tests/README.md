# Unit Tests

These unit tests have been designed to test both deterministic and non-deterministic (LLM) functions.

Due to the stochastic nature of LLMs, these is a non-zero chance some tests will fail.

### ⚠️ Important Notice to Users ⚠️

All data found in this repository is entirely synthetic.

Whilst you may see data that looks real in `tests/*`, it is not real and it purely artificial.

For more information please look at `docs/synthetic_data_limitations`.

### Running Unit Tests

Open a terminal in the root of this repository.

Run `pytest tests/*`
